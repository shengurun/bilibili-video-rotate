# Bilibili 播放器旋转 / 缩放 / 镜像

> 现在 Bilibili 已经进入了“大航海时代”，有很多视频为了防止被下架，都采用了旋转、翻转的操作。这些变动在手机端很容易处理，但是网页端使用起来就有些麻烦了。于是为了自己快乐补番、追剧，就弄了个脚本来提升自己的体验。

一个运行在 B 站网页端的用户脚本：把播放器里的 `<video>` 画面旋转、镜像或缩放，并根据旋转后的真实画面自动适配播放器。弹幕、字幕和控制条保持正向，不跟着转。

## 功能

- 逆时针 / 顺时针 90° 步进，支持 ±15° 微调
- 水平镜像、垂直镜像
- 50%–300% 缩放
- 「完整显示」与「铺满」两种适配方式
- 悬浮按钮单击快速切换，右键打开控制面板，可拖动并吸附到屏幕边缘
- 网页全屏 / 原生全屏下按浏览器窗口重新适配，并自动隐藏悬浮 UI
- 只变换视频画面，不旋转弹幕、字幕和控制条
- 悬浮按钮位置与适配方式会保存；变换状态在当前标签页会话内保留

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 或兼容的用户脚本管理器（如 Violentmonkey）。
2. 打开 [`bilibili-video-rotate.user.js`](https://raw.githubusercontent.com/shengurun/bilibili-video-rotate/main/bilibili-video-rotate.user.js)，在脚本管理器中确认安装；也可以新建脚本后粘贴文件全部内容并保存。
3. 打开 B 站视频页或番剧页，页面右侧会出现圆形旋转按钮。


## 使用

### 悬浮按钮

按钮默认位于屏幕右侧居中，半透明显示；画面处于旋转、缩放或镜像状态时变为蓝色。

| 操作 | 效果 |
| --- | --- |
| 单击 | 在「原始画面」与「逆时针 90°」之间切换；镜像状态保留，缩放回到 100% |
| 右键 | 打开 / 关闭控制面板 |
| 拖动 | 松手后吸附到屏幕左边缘或右边缘，垂直位置会保存 |
| 点击面板外部 / 按 Esc | 关闭控制面板 |

进入网页全屏或原生全屏后，悬浮按钮和控制面板会自动隐藏；退出全屏后按钮回到原位置。

### 控制面板

右键悬浮按钮打开面板，可进行更细的调整：

| 区域 | 说明 |
| --- | --- |
| 角度 | 显示当前角度，范围归一到 -180°–180° |
| `↺ -90°` / `↻ +90°` | 逆时针 / 顺时针旋转 90° |
| 微调 | 滑杆范围 -15°–+15°，步进 0.5°；也可用 `-1°`、`归零`、`+1°` 按钮 |
| 水平镜像 / 垂直镜像 | 即时翻转对应方向；两向同时开启时视觉上等同 180°，但角度仍显示 0° |
| 缩放 | `−` / `+` 每次调整 10%，范围 50%–300% |
| 铺满 / 完整显示 | 旋转后按画面实际占用区域缩放：完整显示保证画面全部可见，铺满填满播放器（可能裁掉边缘） |
| 重置 | 角度、微调、缩放、镜像全部还原；不改变适配方式和按钮位置 |

「铺满 / 完整显示」只在画面处于旋转状态（非 0° / 180°）时参与自动适配；0° / 180° 时只应用手动缩放。

### 脚本菜单

在脚本管理器图标菜单中还可以使用：

- **旋转 / 还原**：不依赖悬浮按钮的备用开关，全屏时也能用
- **水平镜像 / 还原**
- **垂直镜像 / 还原**
- **重置悬浮按钮位置**：把按钮放回右侧居中
- **输出旋转诊断信息**：在浏览器控制台打印播放器、画面盒、基准区域、缩放和镜像等实测数据

## 行为说明

- 脚本只给 `<video>` 元素加变换，因此弹幕、字幕和控制条保持正向。这是有意取舍。
- 缩放依据视频的真实画面（`object-fit` 内容盒）和播放器 / 窗口的基准区域计算，而不是简单地按元素盒子拉伸。
- 网页全屏 / 原生全屏时，以整个浏览器窗口为基准缩放；超出播放器边界的部分由播放器正常裁剪。
- 旋转、缩放、镜像在同一视频内保留：播放器节点被替换、切换标签页、标签页被浏览器挂起后重载都会恢复；切换视频、分 P / 剧集或点击「重置」才回到 0° / 100% / 无镜像。
- 变换状态只保存在当前标签页会话中（`sessionStorage`），不会跨标签页共享，关闭标签页即失效。
- 窗口尺寸变化、迷你播放器切换、网页全屏 / 原生全屏切换只会重新计算缩放，不重置角度和镜像。
- 默认使用「完整显示」；手动切换为「铺满」后会记住该偏好。
- 只有旋转、微调、缩放会播放短过渡动画；镜像和布局变化即时生效，避免画面闪烁。

## 已知限制

- 面向桌面端 `www.bilibili.com` 的视频页和番剧页，未针对直播和移动端页面适配。
- 只变换视频画面，弹幕、字幕、控制条不会跟着旋转。
- 播放器结构依赖 B 站页面；如果页面改版导致找不到播放器，脚本会静默隐藏，不影响页面本身。

## 常见问题

**按钮没有出现？**  
确认脚本管理器已启用脚本，并刷新视频页。若安装过旧版脚本，请删除旧版；也可以查看脚本菜单中的菜单项是否存在。

**旋转后画面被裁掉？**  
切换到「完整显示」，或适当降低缩放比例。

**弹幕 / 字幕为什么没有跟着转？**  
脚本只变换 `<video>`，这是为了避免弹幕和字幕被一起旋转。需要旋转时请自行判断是否关闭弹幕。

**全屏时找不到悬浮按钮？**  
全屏下悬浮 UI 会自动隐藏，请使用脚本菜单中的「旋转 / 还原」和镜像菜单项。

**切换视频后角度被重置了？**  
切换视频、分 P 或剧集会回到原始画面，这是预期行为。同一视频内切换标签页、播放器重建或标签页被浏览器挂起重载不会重置；状态只保留在当前标签页会话中，关闭标签页后失效。

## 开发

仓库只有一个用户脚本文件，无需构建：

- `bilibili-video-rotate.user.js`：全部逻辑（样式注入、播放器识别、变换计算、悬浮 UI、全屏与尺寸观察）
- `mise.toml`：固定 Node LTS 版本，脚本本身无需 Node

调试媒体身份判断时，可把脚本存储键 `bvr:debug` 设为任意真值（`GM_setValue` 或 `localStorage`）后刷新页面，控制台会打印每次 `detect()` 的 `mediaKey`、`mediaChanged`、`videoChanged` 等字段。

修改后在脚本管理器中重新加载脚本并刷新 B 站页面即可验证。
